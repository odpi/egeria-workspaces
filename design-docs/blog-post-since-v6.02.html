Blueprint Season — 6.1

Four and a half months ago this was one working demo. Now it's a small constellation of apps over Egeria's metadata — time-travel, bulk governance, declarative dashboards — and a Freshstart environment that finally acts like a sibling instead of a stub. This is the 6.1 release.

01
APRIL — MAY

A front door, and a tool worth living in

We opened the period with QuickStart already running and Freshstart — the clean-slate, bring-your-own-metadata sibling environment — still mostly scaffolding. So April and May went into two things: giving both environments a real front door, and turning Egeria Explorer from a type browser into the app people actually reached for.

The type hierarchy stopped being a hand-maintained tree and started building dynamically from Egeria's own live type system — domain grouping, abstract-type filtering, inherited-method display, all derived, none hardcoded. Favorites (later Bookmarks) rolled out across a dozen-plus element types, persisted in Egeria itself against the user's own Person element rather than a side database. Native Likes, Ratings, and Comments landed on every detail pane, sitting alongside a separate user-feedback widget that persists to Postgres — two systems, deliberately kept apart.

The portal stopped being a launcher and became a place with its own opinions: a persona picker, a local-admin panel, a --demo mode with its own account flow.

Obsidian joined as a portal tile, running Dr.Egeria markdown against a live Coco Pharmaceuticals vault. And my-egeria — a Textual TUI served straight into the browser — became the portal's first tile that wasn't React at all.

02
MAY — JUNE

Four new rooms, and a working clock

Egeria Explorer stopped being the only tool in the building. Four purpose-built apps shipped in quick succession, and a capability that touches almost everything — asking "what did this look like on a given date" — got wired into nearly every list and detail view across the whole portal.

The Catalog Jun 6

A dedicated technical asset catalog — infrastructure, data assets, APIs, processes — with tabular data preview and classification filtering.

Egeria Operations Jun 22

Governance engines, engine actions, integration connectors — one place, one non-blocking cache so a slow report never hangs the page.

Egeria Audit Jun 22

Users, accounts, and a shared bidirectional relationship viewer every later app quietly reused.

Lineage Explorer Jun 11

Data lineage centred on a focus asset — and the birthplace of the time-slider every other app later borrowed.

That time-slider is the real story here. as_of_time — genuine time travel, not a UI trick — shipped for Data Assets, Digital Products, Collections, Locations, Communities, Perspectives, Glossary, Projects, and Actors. Each one verified against a real before/after: count real data "now," get "no elements found" at a date before it existed. Along the way we also stopped passing passwords in URLs — a shared token seam with automatic 401 retry replaced every user_id/user_pwd query param in the app — and cut Jupyter loose from a public, multi-tenant Kroki service that had been quietly crashing under its own load by self-hosting it.

03
JULY

Search that means it, dashboards built to last

July had two headline efforts, and they turned out to rhyme. One was a proper cross-cutting governance search app. The other was the decision to stop hand-wiring dashboard tiles as React state and start treating them as real, declarative metadata — the choice that made everything in Egeria Overview possible.

Egeria Insights Jul 15

Classification- and zone-faceted search over Egeria's native query engine. Later renamed Query — because that's what it actually does.

Egeria Overview Jul 22

A KPI dashboard for the whole demo, built on a registry — not a page of hand-coded numbers.

Every KPI tile became a real pyegeria FormatSet object — one source of truth instead of six hand-synced places. A Container/Placement model made "perspective" a genuine filtered lens rather than a second hardcoded list. And a Vega-Lite chart engine — line, area, scatter, funnel — took over anywhere the picture wasn't literally a diagram, which is Mermaid's actual job.

Maybe the sleeper feature of the whole quarter: you can now run a Dr.Egeria markdown document straight from the browser. No docker exec. Just paste, validate, process.

Four governance panes — Naming Vocabulary, Policy Enforcement, Action Center, Duplicate Review — closed out four open items from the type-coverage gap analysis in the same stretch.

04
AUGUST

Dashboards for everyone, and closing the gap

August was two things happening at once. The reporting model from July went out to actual users — dashboards anyone can build from a markdown file. And in parallel, a much less glamorous but arguably more important thread went back through Freshstart, line by line, to close the gap that four months of quickstart-first development had quietly opened.

  • Local Dashboards — browse and run user-authored Dashboard Sheets inline, with sparkline KPI tiles, drill-down navigation, and viewer-facing parameter overrides, plus the caching layer that became necessary once all of that made page loads slow.
  • Governance Metrics browser — real GovernanceMetric elements linked to a Report, each documenting its own conceptual data flow as an Information Supply Chain.
  • Bulk actions grew from "add to collection" into zone membership and then classify/declassify across Confidentiality, Criticality, and Impact — rolled out to roughly thirty list views, then ported to Freshstart in full.
  • HTTPS by default, everywhere, both environments, with a Let's Encrypt fallback for the public demo.

The Freshstart audit found real drift, not just cosmetic gaps: a stale MCP API, missing cache headers, and — the sharpest find — a silently broken async-token pattern that reintroduced the exact RuntimeError class this codebase's own conventions exist to prevent. Most of the rest of the divergence turned out to be legitimately by design. Knowing which was which was the actual work.

Underneath all of it

227 fixes shipped alongside the 228 features — real production concerns, not polish. A Postgres connection leak that periodically took Operations offline. A stale-bind-mount bug class that made config edits silently not take effect. A browser-cache issue that turned one shared-JS edit into a blank page for anyone with an old cached copy. A recurring pattern of pyegeria methods that accepted as_of_time and quietly ignored it.

And underneath the fixes, a shared component library — egeria-shared-ui.js — grew from an idea into the thing five-plus apps in both environments actually import from, closing years of copy-paste drift on the components that mattered most. The whole port scheme got renumbered onto a clean 88xx/78xx block, freeing the one port everyone's laptop already had something else running on.
