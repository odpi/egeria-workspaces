**Links between the Patterns of Information Management**

Three kinds of link are generated from the book:

- **Specialized** — every pattern group has a *lead pattern* that "describes the core principles
  and capabilities of the group"; the other patterns in the group "enhance one or more
  characteristics of the lead pattern to support a more specialized situation" (Chapter 1).
- **Nested** — a pattern used as a component in the solution of another pattern.  Chapter 1:
  "a pattern can be used as a component in the solution described by another pattern.  When
  this occurs, the icon of the pattern is used in the solution diagram of the consuming pattern."
  These are taken from the small-capital references in each pattern's Solution section.
- **Related** — the cross-references in each pattern's *Related Patterns* section.
