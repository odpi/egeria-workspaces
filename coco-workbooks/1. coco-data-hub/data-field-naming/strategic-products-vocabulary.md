This file extends the **Data Field Naming Glossary** with the vocabulary needed to name the data fields
of the [strategic digital products](../strategic-digital-products/README.md).  The products cover manufacturing,
serialisation, safety, finance, procurement, people and privacy - subject areas the original glossary touched
lightly or not at all - and their 73 new prime words, 161 new modifiers and 6 new class words are
added here, each into the subject-area folder it belongs to, rather than scattered across the subject-area files.

The convention is unchanged: a field name is a prime word, zero or more modifiers, and a class word, in that
order, e.g. `SafetyCaseReportingDueDate` = `SafetyCase` + `Reporting` + `Due` + `Date`.  Every field in the
product data specifications decomposes that way using this vocabulary and the original.

Process this file after the subject-area files and `common-class-words.md`, and before the three `classify-*.md`
files, which classify the terms created here alongside the originals.

____

# Common Class Words

## Create Glossary Term

### Display Name
Timestamp

### Glossary Name
- Glossary::DataFieldNaming

### Summary
A point in time recorded to the second or finer, e.g. `OrderReceivedTimestamp`.  Use `Date` where only the calendar day matters.
