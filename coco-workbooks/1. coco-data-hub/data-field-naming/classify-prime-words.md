This file runs the **Classify Prime Word** command against every term held in a
Prime Words folder of the Data Field Naming glossary, attaching the `PrimeWord` classification from
[0438 Naming Standards](https://egeria-project.org/types/4/0438-Naming-Standards/).

Prime words are the core business nouns that a data field name is built around - the `Patient` in
`PatientAdmittingDate`. The classification lets tools recognise a term as the anchor of a field name
rather than a qualifier (`Modifier`) or a value-type suffix (`ClassWord`).

Prime words are collected here rather than alongside their `Create Glossary Term` command so that
every term already exists before it is classified - process this file after all the subject area
files listed in `README.md`.

56 terms are classified below, grouped by subject area.
