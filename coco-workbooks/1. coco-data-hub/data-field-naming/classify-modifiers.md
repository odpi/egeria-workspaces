This file runs the **Classify Modifier** command against every term held in a
Modifiers folder of the Data Field Naming glossary, attaching the `Modifier` classification from
[0438 Naming Standards](https://egeria-project.org/types/4/0438-Naming-Standards/).

Modifiers qualify a prime word or a class word - the `Admitting` in `PatientAdmittingDate`. The
classification lets tools recognise a term as an optional qualifier rather than the anchor of a field
name (`PrimeWord`) or its value-type suffix (`ClassWord`).

Modifiers are collected here rather than alongside their `Create Glossary Term` command so that
every term already exists before it is classified - process this file after all the subject area
files listed in `README.md`.

205 terms are classified below, grouped by subject area.
