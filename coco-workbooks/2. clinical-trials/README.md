# Clinical Trials

Coco Pharmaceuticals decide to invest in the pipelines and processes that receive data from a hospital as part of a clinical trial.  This process must be carefully monitored to be sure that the data used to measure the effectiveness of new drugs is accurate.

The [receive-data-from-hospitals.ipynb](receive-data-from-hospitals.ipynb) walks through the process of setting up new clinical trials and receiving data.  Its aim is to demonstrate fine-grained lineage and data mappings along with the use of certifications to control the flow of data.
