## Overview

The [data security strategy](../0.%20data-governance-program/data-security-strategy.md) commits Coco Pharmaceuticals to ISO/IEC 27001:2022 certification, and its certification type says that "a Statement of Applicability must be maintained, recording which Annex A controls are applicable and how they are implemented".  This is that statement.  Simon Burr started it in his first ninety days as CISO, and it is the main document the certification body will review.

It is built from three kinds of element:

* a **governance control** for each Annex A control that has been assessed;
* the **statement of applicability** itself, governed by the ISO/IEC 27001 certification type and scoped to the organization;
* a **control applicability** link from the statement to each control, recording whether the control applies, the justification, the reasons for including it, how far it has been implemented, how it is implemented and when it was last reviewed.

The controls are also linked to the security obligations they implement, so the statement is connected to the rest of the security governance program rather than standing alone.

### About the controls

Annex A of ISO/IEC 27001:2022 has 93 controls in four themes: organizational, people, physical and technological.  This workbook covers the 15 that Simon assessed first, chosen because they respond to the risks in the [risk register](../0.%20data-governance-program/risk-register.md).  The rest are added as they are assessed.

The standard is copyrighted by ISO and IEC.  Each control below carries the standard's number and title so that it can be identified, and a description in Coco Pharmaceuticals' own words.  The authoritative text is in Coco Pharmaceuticals' licensed copy of the standard.

### Keeping the statement up to date

Linking a control that is already linked updates its applicability.  As a control's implementation progresses, change its *Implementation Status*, *Implementation Description* and *Review Date* in this file and process it again.

## Create Statement of Applicability

### Display Name
Coco Pharmaceuticals ISMS Statement of Applicability

### Qualified Name
CocoPharma::StatementOfApplicability::ISMS

### Description
Records which controls from Annex A of ISO/IEC 27001:2022 apply to Coco Pharmaceuticals' information security management system, why each is included or excluded, and how far each has been implemented. Coco Pharmaceuticals' information security management system: the research systems holding personalised treatment intellectual property, the manufacturing control systems, corporate IT, and the data shared with hospital and research partners, across the Coco Pharmaceuticals, Austin and Bucharest estates.
